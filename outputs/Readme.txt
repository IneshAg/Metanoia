Metanoia V2 for Windows

Double-click Open-Metanoia.cmd or Metanoia V2.exe.
This is the React/TypeScript V2 packaged as a native Tauri Windows app. It saves V2 tasks, courses, habits and Focus history in its own local SQLite workspace.

In Focus, add songs or select a folder. Music remains in its original location. Like and dislike choices are saved in the app's SQLite database; select the folder again after restarting to play those files.

This portable build requires the Microsoft Edge WebView2 runtime, already present on the tested machine.
An installer is not included because the local NSIS executable fails to start on this Windows installation; the app executable itself built and launched successfully.
